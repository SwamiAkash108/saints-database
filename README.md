# ☦ Saints Database — All Catholic & Orthodox Saints

A comprehensive, self-contained searchable HTML database of **10,583 Christian saints** — both Catholic and Eastern Orthodox — including major and minor saints from worldwide traditions.

## Features

- 🔍 **Full-text search** across names, biographies, and relic locations
- 📅 **Feast days** for 2,541 saints
- 📖 **Short biographies** for 3,728 saints
- 🪦 **Relic locations** for 1,498 saints
- 🏷️ **Tradition filter** — Catholic / Orthodox / Both
- 📄 **Alphabetical jump navigation**
- 📱 **Responsive Paper BW design**
